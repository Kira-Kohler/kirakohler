01 — Overview

Two Components, One System

K1R4LΛBS consists of two separate products that work together to give you access to Valorant features inside Discord:

🤖

K1R4LΛBS Discord Bot

Provides Valorant commands directly in Discord — store viewer, match history, agent lock, skin changer, and more. Stores your encrypted Valorant session so commands work without re-logging each time.

🧩

K1R4LΛBS Browser Extension

Optional Chrome/Chromium extension used exclusively for account login. Reads your Riot session cookie from the browser and sends it to the bot once — it never runs in the background or stores anything.

They complement each other: the extension handles the one-time login handshake in a simple, secure way, while the bot stores the resulting encrypted session so all your subsequent commands work instantly.

This policy applies to both products. Sections 02–05 cover the browser extension. Sections 06–10 cover the Discord bot. The remaining sections apply to both.

🧩 Browser Extension
02 — Extension Purpose

What the Extension Does

The K1R4LΛBS extension has one single purpose: simplifying the Valorant account login process for the Discord bot. It replaces a multi-step manual flow (copying OAuth callback URLs) with a one-click experience.

The extension is completely optional. You can log into the bot manually through a Riot OAuth link instead. The extension simply makes this easier.

The extension does not run in the background, does not monitor your browsing, does not inject scripts into pages, and does not store any data locally.

🧩 Browser Extension
03 — Extension: Login Flow

How the Extension Login Works

The login process happens in a single session when you open the extension popup. Here is the exact sequence:

01
You generate a code in Discord
The bot generates a temporary 6-digit numeric code, valid for 3 minutes, stored only in memory.
02
You open the extension popup
The extension reads the ssid cookie from riotgames.com in your browser. This cookie is your active Riot session. It is read only at this moment — not monitored continuously.
02b
The extension fetches your Riot game name (display only)
To show your account name in the popup UI, the background script makes two calls to Riot's official API: a POST to auth.riotgames.com/api/v1/authorization (injecting your SSID via a temporary request header rule) to obtain a short-lived access token, then a GET to auth.riotgames.com/userinfo to retrieve your game name and tag line. The access token and userinfo are used only for this display — they are never stored or sent anywhere. The header rule is removed immediately after.
03
You enter the 6-digit code and click Send
The extension sends a single HTTPS POST to the bot's auth server (auth.kirakohler.es) containing the code and the SSID cookie value.
04
The bot validates and creates your session
The bot verifies the code is valid and not expired, then uses the SSID to obtain Riot OAuth tokens. The session is encrypted and saved. The 6-digit code is immediately discarded.
05
Done — extension work is finished
The extension shows confirmation. It holds no data after this. The popup can be closed.
🧩 Browser Extension
04 — Extension: Permissions

Extension Permissions Explained

The extension requests two browser permissions:

  • cookies — Lets the extension read your active Riot session from the browser. This is how it knows you are already logged into Riot — it reads one specific session value from the Riot website only. It cannot read cookies from any other website.
  • declarativeNetRequest — Lets the extension attach your Riot session to a request it makes to Riot's own servers, in order to look up your in-game name and show it to you in the popup. This only affects requests to Riot's official domain and only while you have the popup open.

The extension can only ever interact with Riot's official website (riotgames.com). It has zero access to any other site, your browsing history, your passwords, or any other accounts.

The extension stores nothing in chrome.storage, localStorage, or any other persistent mechanism. Every time you open the popup, it reads the cookie fresh and starts clean.

08 — Bot: Session Auto-Renewal

How Token Renewal Works

Riot OAuth access tokens expire after roughly one hour. To avoid asking you to re-login constantly, the bot uses the stored SSID session cookie to silently obtain a fresh token in the background. This happens:

  • Automatically when you run a command and your token has expired
  • Proactively at 00:01 UTC daily, before sending store notifications

During renewal, the bot sends the SSID to the official Riot Auth API (auth.riotgames.com) over HTTPS. The SSID is never sent to any other server. If renewal fails (e.g. your Riot password changed), you will be prompted to log in again manually.

The SSID cookie is used exclusively to maintain your bot session. It is never used to interact with the Riot game client, access your Riot account settings, or perform any action beyond obtaining API tokens.

10 — Bot: Third-Party Services

Third-Party Services Used

The bot communicates with external services during normal operation:

  • Riot Games APIs — Used to authenticate your account and retrieve Valorant data such as your store, locker, and match state. Your encrypted tokens are sent only to official Riot endpoints over HTTPS.
  • valorant-api.com — A public database of Valorant weapon skins, agents, and cosmetics. No personal data is sent. Used to display item names and images.
  • Discord API — Standard API usage for receiving commands and sending responses, including daily store DMs if you have opted in.

No personal data from your Valorant session is ever shared with third-party services. Riot credentials are sent exclusively to official Riot endpoints.

11 — Security

How We Protect Your Data

We take the following measures to protect the data the bot stores:

  • AES-256-GCM encryption — All Valorant credential data (tokens, SSID, PUUID, game name, region) is encrypted at rest using AES-256-GCM with a random 12-byte IV and 16-byte auth tag per record. The encryption key is stored as a server environment variable, never in code.
  • HTTPS only — All communications with Riot APIs and the extension auth endpoint use HTTPS. No credentials are transmitted in plain text.
  • Sandboxed execution — The bot runs in a restricted environment with no unnecessary system permissions.
  • No external logging — No analytics platforms, error-tracking services, or logging databases are integrated. Command inputs and outputs are not logged.
  • Isolated headless browser sessions — Each screenshot request creates and destroys a separate browser session with no persistent state.
  • Short-lived auth codes — The 6-digit extension login code expires after 3 minutes and is stored only in bot memory, never on disk.
12 — Your Rights & Data Deletion

Accessing and Deleting Your Data

You are in control of the data the bot holds about you:

  • Delete a specific account session — Use /valo logout in Discord. This immediately removes that account's encrypted session from the server. There is no recovery after logout.
  • Disable store notifications — Use /valo config to opt out. Your notification preference is updated immediately.
  • Request complete data deletion — Contact the bot owner through the official Discord server. All data associated with your Discord user ID (sessions, preferences, configs, permission entries) will be removed within a reasonable timeframe.
  • Right to know what is stored — You can request a description of the data associated with your Discord ID at any time by contacting us.

Under GDPR, CCPA, and similar regulations, you have the right to access, correct, and delete your personal data. We honor these rights as described above.

/valo logout is the fastest way to remove your Valorant data. It takes effect immediately and requires no assistance from the bot owner.
